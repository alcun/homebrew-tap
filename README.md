# alcun/tap

```sh
brew install --cask alcun/tap/heyra
brew install --cask alcun/tap/alt-tabber
```

- **heyra**: hold fn, talk, let go. Push-to-talk dictation that runs on your Mac.
  [alcun/heyra-desktop](https://github.com/alcun/heyra-desktop)
- **alt-tabber**: Option-Tab through every window, on every Space. Free, nothing to upgrade.
  [alcun/alt-tabber](https://github.com/alcun/alt-tabber)
